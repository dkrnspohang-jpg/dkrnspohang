연결 설정

※ 같은 Firebase 설정과 팀 코드를 쓰는 PC끼리 실시간으로 공유됩니다. 설정값은 이 브라우저에 저장됩니다.

설정 방법 (약 5분, 1회만)

  1. 구글 계정으로 console.firebase.google.com 접속 → 프로젝트 추가(이름 예: dgrns-pohang, 애널리틱스는 꺼도 됨)
  2. 왼쪽 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3(서울) → 테스트 모드로 시작
  3. 프로젝트 개요 옆 ⚙️ → 프로젝트 설정 → 아래 내 앱에서 </> 웹앱 추가 → 앱 등록
  4. 표시되는 firebaseConfig 의 중괄호 { } 안 내용을 복사해 위 칸에 붙여넣고 연결
  5. 첫 PC에서 ⬆️ 이 PC → 팀 전체 올리기 1회 실행 → 다른 PC들은 같은 설정 붙여넣고 연결하면 자동으로 받아집니다.
보안 규칙 : Firebase 콘솔 → Firestore Database → 규칙 탭에서 아래 규칙을 게시하면 만료 없이 사용됩니다. (테스트 모드로 두면 30일 후 차단)
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /dgrns_rooms/{room}/data/{doc} { allow read, write: if true; } match /{document=**} { allow read, write: if false; } } }
※ 규칙은 콘솔에, 위의 firebaseConfig는 이 화면에 붙여넣습니다. 자세한 절차는 Claude 폴더의 모바일_접속안내.html 참고.
